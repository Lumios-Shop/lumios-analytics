1. Executive Summary & Tool Overview

Lumios Analytics is a proprietary, internal executive dashboard built specifically for Lumios le Jeu. The tool consolidates multi-channel e-commerce performance metrics (Shopify sales, Amazon SP-API orders, shipping costs, payment gateway fees, and advertising expenditures) into a single unified financial P&L view.

The primary goal of integrating the Google Ads API is to automatically retrieve daily advertising spend metrics to calculate accurate ROAS (Return on Ad Spend), CPA (Cost Per Acquisition), and Net Profit Margins in real time.

2. Google Ads API Scope & Usage Details

The application requires Read-Only Access to basic performance reporting data via the Google Ads API REST endpoints:

  • Query Types: Google Ads Query Language (GAQL) queries requesting daily cost metrics.
  • Fields Requested: segments.date, metrics.cost_micros from the customer resource.
  • Access Frequency: Automated once-daily sync job to fetch previous day spend.
  • No Write Operations: The tool does NOT modify, create, manage, or delete any Google Ads campaigns, ads, keywords, or budgets.

3. Key Dashboard Features & Workflow

Feature Component Description & Metric Data Source
Financial P&L Table Aggregates Gross Revenue (Shopify + Amazon) minus Discounts, Returns, Shipping Costs, Payment Fees, and Google/Meta Ad Spends.
ROAS & CPA Analytics Calculates overall Return On Ad Spend (Total Revenue / Total Ad Spend) and Cost Per Acquisition (Total Ad Spend / Order Count).
Net Margin Calculator Deducts 20% VAT/TVA, COGS (Product Costs), shipping rates, and ad spend to provide net HT/TTC net profit margins.

4. Data Storage, Security & Compliance

  • Data Isolation & Privacy: All data fetched from the Google Ads API is strictly used for internal reporting of Lumios le Jeu. Data is never shared with third parties, sold, or exposed publicly.
  • Secure OAuth 2.0 Flow: Authentication uses Google OAuth 2.0 with offline access (Refresh Token) restricted exclusively to authorized internal company accounts.
  • Local Secure Storage: Metrics are cached in a private, encrypted local database strictly accessible within the company server environment.
